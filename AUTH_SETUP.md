# Настройка системы аутентификации

## Важно: Порядок запуска

**Сначала запустите PostgreSQL, затем бэкенд!**

## Запуск PostgreSQL в Docker

1. Запустите PostgreSQL контейнер:
```bash
docker-compose up -d postgres
```

2. Проверьте, что контейнер запущен и готов принимать подключения:
```bash
docker ps
docker exec java-course-postgres pg_isready -U java_course_user -d java_course_db
```

Должно вывести: `/var/run/postgresql:5432 - accepting connections`

## Запуск бэкенда

1. Перейдите в директорию `backend`
2. Убедитесь, что PostgreSQL запущен
3. Запустите приложение:
```bash
./mvnw spring-boot:run
```

Или используйте IDE для запуска `BackendApplication.java`

## Запуск фронтенда

1. Перейдите в директорию `frontend`
2. Установите зависимости (если еще не установлены):
```bash
npm install
```

3. Запустите dev сервер:
```bash
npm run dev
```

## Использование

1. Откройте браузер и перейдите на `http://localhost:3000`
2. Нажмите кнопку "Регистрация" в хедере
3. Заполните форму регистрации (email, имя, пароль минимум 6 символов)
4. После регистрации вы автоматически войдете в систему
5. Для входа используйте кнопку "Войти"
6. Для выхода используйте меню пользователя в хедере

## API Endpoints

- `POST /api/auth/register` - Регистрация нового пользователя
- `POST /api/auth/login` - Вход в систему
- `POST /api/auth/logout` - Выход из системы
- `GET /api/auth/me` - Получить информацию о текущем пользователе

## База данных

База данных автоматически создается при первом запуске благодаря настройке `spring.jpa.hibernate.ddl-auto=update`.

Таблица `users` содержит следующие поля:
- `id` - уникальный идентификатор
- `email` - email пользователя (уникальный)
- `password` - хешированный пароль (SHA-256)
- `name` - имя пользователя
- `created_at` - дата создания
- `updated_at` - дата обновления
