# Проверка SSH подключения к вашему серверу

## Ваши данные сервера:
- **IPv4:** 5.129.200.192
- **IPv6:** 2a03:6f00:a::1:4027
- **Пользователь:** root
- **Порт SSH:** 22 (стандартный, не указан в команде)

## Команда для подключения:

```bash
ssh root@5.129.200.192
```

Или с явным указанием порта:
```bash
ssh -p 22 root@5.129.200.192
```

## Проверка в GitHub Secrets:

Убедитесь, что в GitHub Secrets (Settings → Secrets and variables → Actions) указано:

- `DEPLOY_HOST` = `5.129.200.192`
- `DEPLOY_USER` = `root`
- `DEPLOY_PORT` = `22` (или можно не указывать, если используется стандартный порт)

## Если подключение требует SSH ключ:

Если при попытке подключения запрашивается пароль, вам нужно настроить SSH ключ:

1. **Сгенерируйте SSH ключ** (если еще нет):
   ```bash
   ssh-keygen -t ed25519 -C "github-actions"
   ```

2. **Скопируйте публичный ключ на сервер:**
   ```bash
   ssh-copy-id root@5.129.200.192
   ```
   
   Или вручную:
   ```bash
   cat ~/.ssh/id_ed25519.pub | ssh root@5.129.200.192 "mkdir -p ~/.ssh && cat >> ~/.ssh/authorized_keys"
   ```

3. **Добавьте приватный ключ в GitHub Secrets:**
   - Скопируйте содержимое приватного ключа: `cat ~/.ssh/id_ed25519`
   - Добавьте в GitHub Secrets как `DEPLOY_SSH_KEY`
   - **Важно:** Копируйте весь ключ, включая строки `-----BEGIN ...` и `-----END ...`

## Проверка подключения:

Попробуйте подключиться:
```bash
ssh root@5.129.200.192
```

Если подключение успешно, вы увидите приглашение командной строки сервера.

## Если подключение не работает:

1. **Проверьте файрвол на сервере:**
   ```bash
   # На сервере выполните:
   sudo ufw status
   sudo ufw allow 22/tcp
   ```

2. **Проверьте, что SSH сервис запущен:**
   ```bash
   # На сервере:
   sudo systemctl status sshd
   ```

3. **Проверьте доступность порта:**
   ```bash
   # С вашего компьютера:
   telnet 5.129.200.192 22
   # или
   nc -zv 5.129.200.192 22
   ```
